# 🚀 Resolve - Support Ticket Management Frontend

The front-end application for the **Resolve** support ticket management system, built with Angular and designed for a smooth, responsive user experience.

---

## 🛠️️ Tech Stack

* **Framework:** Angular (Standalone Components architecture)
* **Routing:** Angular Router with lazy loading / global navigation
* **Forms & Validation:** Reactive Forms
* **HTTP Client:** HttpClient with RxJS (Observables, error handling)
* **Styling:** CSS / Responsive design

---

## ✨ Key Features

* **Authentication UI:** Dedicated Login and Register views with reactive form validation and bidirectional routing.
* **Global Navigation:** Persistent navigation bar reflecting the user's session state and providing global logout functionality.
* **Ticket Dashboard:** View, filter, and interact with support tickets based on user roles.
* **Agent Operations:** Quick actions such as "Take Charge" to assign tickets directly to active agents.
* **Secure Routing:** Protected routes ensuring unauthenticated users are redirected to the login page.

---

## ⚙️ Quick Start

### Prerequisites
* Node.js & npm installed
* Angular CLI (`npm install -g @angular/cli`)

### 1. Install Dependencies
\`\`\`bash
npm install
\`\`\`

### 2. Run the Development Server
\`\`\`bash
ng serve
\`\`\`
*(The application will be available at `http://localhost:4200`)*
