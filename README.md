# Resolve - Support Ticket App (Front-End)

A front-end application built with **Angular** for managing support tickets.

## Tech Stack

* **Framework:** Angular (Standalone Components)
* **Language:** TypeScript
* **Communication:** Angular HttpClient interacting with a .NET 9 REST API

## Features

* **Dynamic Ticket Dashboard:** View and track support tickets with real-time local state updates.
* **Interactive Creation Form:** Seamless ticket submission (`Title`, `Description`, `Priority`) with instant UI reflection.
* **AI Analysis Display:** Dedicated UI section on each ticket card to render recommendations generated by Google Gemini via the backend.
